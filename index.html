    HOW TO RUN THE WORKSHOP

    Simple classroom structure

    015 minutes · Set the challengeDivide pupils into groups of four and assign one research mission per group.
    0220 minutes · Research and buildEach team uses one device to read, research and make a thought board.
    035 minutes · PrepareEach group agrees on its main conclusion and chooses a spokesperson.
    04Afterwards · Teach the classAllow roughly two minutes per team, followed by reflection and questions.
    CLOSING DISCUSSION

    Beyond the inventions

    What problems drove the innovations you discovered?

    Which mattered more: the invention, the people or the conditions around them?

    Where do we see resilience, collaboration and creative thinking?

    Were there trade offs, failures or unintended consequences?

    What lessons could other societies learn from these examples?

    PLEASE NOTE

    Built for GitHub Pages

    Boards save to each group's browser. A group uses one device, then sends the teacher a share link. Opening the link does not change the original board.

    This is not a live shared workspace. If you need pupils to edit the same board from different devices at once, a separate online database would be needed.

    No pupil accounts or personal data service is required. Remind groups to use team names rather than sensitive personal details.
